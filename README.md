# Sri Ganapathy Traders

Premium construction materials website for Sri Ganapathy Traders, Nagercoil.

## 🏗️ Features

- **Multi-page Website**: Home, Products, Brands, About, Wholesale, and Contact pages
- **Cinematic Animations**: GSAP and Framer Motion for smooth, professional animations
- **Responsive Design**: Fully responsive across desktop, tablet, and mobile
- **WhatsApp Integration**: Functional contact forms with WhatsApp integration
- **SEO Optimized**: Meta tags, sitemap, and robots.txt for local search visibility
- **Premium Design**: Industrial-themed design with custom color palette

## 🛠️ Technology Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP, ScrollTrigger, Framer Motion
- **Icons**: Lucide React
- **Fonts**: Barlow Condensed, DM Sans

## 📱 Products & Brands

## 🚀 Getting Started

### Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Build

```bash
npm run build
npm start
```

### Deploy

The website is configured for Vercel deployment. Push to the repository and Vercel will automatically deploy.
